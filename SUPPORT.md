# Onwan Support / دعم عنوان

> **INTERNAL — this note is stripped from the published page.** Published at
> `https://onwan.eu/support` on 2026-07-28, because the Google Workspace Marketplace requires a
> support URL alongside privacy and terms. The support channel is the owner's monitored mailbox, so
> the response target below is a commitment, not an aspiration — revise it here if that changes.

## English

Support email: [support@onwan.eu](mailto:support@onwan.eu)\
Response target: within one business day\
Support languages: Arabic and English\
Service days/time zone: Monday–Friday, Europe/Berlin; no 24/7 support

When asking for help, include:

- the approximate time of the problem;
- the Onwan action you ran;
- the interface and project language;
- the request ID or error code;
- a redacted screenshot if useful.

Do **not** send licence codes, API keys, passwords, or unredacted documents.

## No-fee access

Onwan is free to use and is funded by grants for public-interest journalism. Nothing is sold, there is
no paid tier, and no feature is reserved for payment. Every account has a free allowance; if yours runs
out, write to the address above and further access may be added at no charge, as capacity allows.
Write from the same Google account you use with Onwan, so the access can be matched to you.

To stop using Onwan, uninstall the add-on and revoke its access in your Google Account security
settings. For access, correction, or deletion requests, write to
[support@onwan.eu](mailto:support@onwan.eu).

ولا تُحجز أي ميزة مقابل الدفع. لكل حساب حد مجاني؛ وإذا استُنفد، راسل العنوان أعلاه وقد يُضاف مزيد من
